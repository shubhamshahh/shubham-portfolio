## 🚀 How to Run & Preview Locally

1. Simply double-click `index.html` to open it in any web browser (Chrome, Edge, Firefox, Brave, Safari).
2. Or run a lightweight local server:
   ```bash
   npx serve .
   # or
   python -m http.server 3000
   ```
